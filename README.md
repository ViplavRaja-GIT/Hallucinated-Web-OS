# Hallucinated Web OS
A browser-based experimental operating system experience powered by AI.

Hallucinated Web OS transforms a traditional chat interaction into a dynamic desktop environment where applications, windows, and system actions can be generated, modified, and controlled through natural language. Instead of navigating a fixed interface, users interact with an AI that can create and orchestrate an application on demand.
---

## Demo
[Watch the demo video](./final.mp4)

## ✨ Features
* Window-based user interface
* Draggable and resizable applications
* Multi-window support
* Desktop shortcuts and workspace management
* Taskbar and application launcher
* Create applications using natural language
* Context-aware system interactions
* Can save apps in local storage
---

## 🚀 Getting Started
### Prerequisites
* Node.js 18+
* npm, pnpm, or yarn

### Installation
```bash
git clone <repository-url>
cd hallucinated-web-os

npm install
```

### Run Development Server
```bash
npm run dev
```
Open:
```text
http://localhost:5173
```

## 🔮 Vision
Hallucinated Web OS explores a future where operating systems are no longer limited by predefined applications and interfaces. Instead, the environment itself becomes adaptive, generating tools, workflows, and experiences in response to user intent.

The goal is to blur the line between operating system, application platform, and AI assistant—creating a workspace that evolves dynamically as users work.
